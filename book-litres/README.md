# book-litres-v4-mini-debug

Минимальный тест передачи результата JavaScript обратно модели.

JS выполняет только один запрос Bing через r.jina.ai и возвращает короткий результат:

DEBUG_OK
HTTP=...
OK=...
LEN=...
HAS_LITRES=...
HAS_BOOK=...
HAS_AUTHOR=...
HAS_KUBERNETES=...
HAS_TITLE_RU=...

Если Gemma не показывает даже это, проблема почти наверняка в обработке результата run_js, а не в парсере поиска.
