# book-litres-v3

Рабочая версия после raw-debug.

Что изменено:
- модель больше не получает сырой Bing/Jina ответ;
- поиск и извлечение URL выполняются внутри JavaScript;
- модели возвращается короткий JSON;
- URL LitRes передаётся как отдельное поле;
- страница книги и /reviews/ читаются отдельно;
- рейтинг/счётчики извлекаются в JS, если удаётся;
- reviewEvidence ограничен по длине.
