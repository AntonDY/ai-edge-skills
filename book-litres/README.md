# book-litres-raw-debug

Минимальная диагностическая версия Agent Skill для Google AI Edge Gallery.

Она:
1. распознаёт название/автора через модель;
2. вызывает index.html;
3. выполняет один запрос Bing через r.jina.ai;
4. возвращает сырой ответ без парсинга;
5. просит модель вывести его без сокращений.

Ожидаемый маркер в ответе:

DEBUG BOOK-LITRES
